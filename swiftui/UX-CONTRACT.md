# カタログを探し、試し、診断を共有する画面仕様

対象は日本語を読む開発者とテスター。iPhone の縦画面を出発点に、ユーザーが目的から機能を見つけ、利用条件を確認し、操作結果や性能を調べる。日付や金額が意味を持つサンプルは、個別の README に暦・タイムゾーン・通貨を記載する。診断形式の UTC 時刻と画面上の日付表示は用途を区別する。

サンプルの目的と検証条件は [作業計画](docs/PLAN.md)、配色と表示上の優先度は [画面設計](DESIGN.md)、OpenPencil との対応は [デザインファイル](design/README.md) を参照する。

## Canonical UI Map

| Capability | Canonical owner | Source of truth | Allowed variants | Verification |
| --- | --- | --- | --- | --- |
| Select/Listbox | SwiftUI の `Picker` と `.searchable` | サンプルの状態と画面仕様 | ネイティブ選択、検索フィルタ | VoiceOver と日本語キーボードで選択、入力、クリア |
| Date | SwiftUI の `DatePicker`、ドメインの日付検証 | 予定、予約、支出、習慣のサンプル | 単日、日付と時刻 | 月末、年末、日付をまたぐ利用 |
| Form | SwiftUI のフォームとサンプル固有の入力検証 | サンプルのデータモデル | 保存、変更、検証結果 | 入力の保持、エラーからの復帰、二重操作 |
| CRUD | 個別サンプルの状態管理と保存 | サンプル README と状態遷移 | 一覧へ戻る、結果をその場で提示 | 保存、復元、失敗からの再試行 |

## 操作と状態

| 操作 | 表示と次の操作 |
| --- | --- |
| 探す | 目的、サンプル名、技術名を照合する。検索フィールドの消去操作で一覧に戻る。検索結果が空のときは、別の検索語を案内する。 |
| 案内から開く | 試せる操作と利用条件を先に表示する。権限は必要になったときに iOS の許可画面で確認する。 |
| 接続を選ぶ | 実接続、端末内、再現用データを案内で示す。実サービスを使う操作では端末や通信の条件を表示する。再現の購入、予約、送信では画面上の状態も再現用であることを明示する。 |
| 読み込み中 | 何を取得・準備しているかを表示する。処理を中止できるときは操作を用意する。多重の実行が状態を書き換える場合は、最初の処理を取り消すか操作を抑止する。 |
| 空・失敗 | 記録が空、検索結果なし、通信失敗、未許可を文言で区別する。続行できる操作を、状態の近くに置く。 |
| 権限・非対応 | 必要な権限と使う機能を表示する。設定から許可できる場合は設定への移動を案内する。非対応端末では利用条件を表示し、代替の入力や再現経路があれば案内する。 |
| 戻る・中断する | カタログからの階層は標準の戻る操作に従う。メディアや通信など画面に付随する処理は、個別サンプルの画面寿命とアプリ状態に合わせて終了または休止する。 |
| 診断する | 端末内での記録状況を表示する。保存エラー時は状態を表示し、記録できた分を確認できる範囲で書き出す。 |
| 書き出しと共有 | 利用者の操作で書き出しを準備した後、iOS の共有先選択を開く。共有を取り消した場合は診断画面に戻る。 |

## 画面と入力の検証

1. 一覧、案内、診断の順に開く。検索に日本語を変換入力し、確定と消去、該当なし、戻る操作を確認する。
2. 外部接続を使うサンプルで通信失敗、カメラを使うサンプルで権限拒否を再現する。状態と再試行や設定の案内を VoiceOver で確認する。
3. ライト・ダーク、通常および最大のアクセシビリティ文字サイズで、説明全文と主要操作へ到達する。タブ、キー入力、ホームインジケータと操作が重ならないことを確認する。
4. 診断の記録状況を読み上げ、書き出し、共有先選択、閉じる操作を確認する。ファイルを共有しない場合と共有する場合を個別に試す。

シミュレータと実機の結果は [検証記録](docs/VERIFICATION.md) に記載する。OpenPencil 上の文字サイズと iOS のアクセシビリティ文字サイズは、それぞれの画面で確認する。
