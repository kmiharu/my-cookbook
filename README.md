# my-cookbook

実務で役立ったサンプルコード集です。必要なファイルやコードの一部をコピーして、自分の環境で使えます。

## サンプル一覧

| できること | 使用技術 | サンプル |
| --- | --- | --- |
| 指定したSQLファイルでPostgreSQLのデータを抽出・更新する。CSV出力にも対応 | BAT / PowerShell / SQL | [postgres-db-operations](./postgres-db-operations/) |
| 商品を登録・更新・検索し、DynamoDB と Aurora PostgreSQL の使い分けや同期を試す | Java / Micronaut / AWS Lambda | [api-sample](./api-sample/) |
| PostgreSQLの顧客をCSVで配布し、受信ファイルやDynamoDBからデータを反映する | Java / Spring Batch / PostgreSQL / AWS SDK | [spring-batch-examples](./spring-batch-examples/) |
| iPhoneで記事、写真編集、動画再生、ARなどのサンプルを選んで試す | SwiftUI / iOS | [swiftui](./swiftui/) |
